# 06 MPS 초음파가이드

MPS EMR 의료진 메뉴에서 연결하는 정적 초음파 교육·참고 가이드입니다.
원본 `mps-ultrasound-portal`은 수정하지 않았습니다.

- 6개 부위, 30개 단계, 질환 정의, 검색, 아틀라스, 관찰 기록, 복사·텍스트 저장·인쇄, RUF 촬영 안내 유지
- ESSR PDF 7개·89쪽과 원본 이미지, 출처·이용조건·연구 참고 자료 복사
- 30개 정상 및 30개 기본 병리 사례에 한국어 관찰 해설 추가
- 25개 단계에 두 번째 병리 또는 감별 그림 연결. 다른 표적 구조와 혼합 영상(자기공명/방사선/컴퓨터단층)은 해설에서 구분
- 원문에 촬영 측이 명시된 경우만 좌·우 표기. 미확인 사례는 ‘좌우 미표기’로 표시
- 영상 자체의 원문 표기는 보존하고, 사진 하단 및 확대창에 한글 해부학 약어표 제공
- 원본 견갑하근 병리 연결 오류 수정: Figure 11 극상근 그림 대신 실제 Figure 13 견갑하근 그림 사용
- 환자 DB, 인증, 설문 저장 경로는 변경하지 않음

## 수정·빌드

`data.json`: 원본 프로토콜·출처·로컬 자산 경로. `teaching.json`: 이미지별 한국어 해설·촬영 측·부위별 약어.
`emr.js`, `emr.css`: EMR 화면 통합. 원본 기능 스크립트를 보존한 채 화면을 확장합니다.

```sh
python3 tools/build_ultrasound.py
python3 tools/build.py
python3 -m unittest discover -s tools -p 'test_*.py'
```

`index.html`, `data.js`, `teaching.js`, `disclaimer.js`는 생성 파일입니다.
`source-manifest.json`은 복사한 기존 이미지·원본 문서 410개의 SHA-256입니다. 추가 그림은 `assets/reviewed/`에 별도로 있습니다.
원본의 대용량 base64 단일파일과 과거 버전 폴더를 중복 제공하는 대신, 동일한 기능에 필요한 모든 이미지와 원본 PDF를 로컬 상대경로로 연결했습니다.

## 관찰 기록의 범위

기존 포털의 교육용 관찰 기록 기능을 유지합니다. 이 페이지의 입력은 현재 탭 메모리에만 남으며 새로고침하면 초기화됩니다. 복사·텍스트 저장·인쇄할 수 있습니다. 환자 차트에 자동 저장하거나 진단을 자동 생성하지 않습니다.
